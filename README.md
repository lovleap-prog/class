# 학교 교육활동 관리

일일 · 주간 · 월간 교육활동을 선생님들이 입력하고, 확인·승인을 거쳐,
**나이스 일일교육활동 결재 문구**와 **한글 문서**로 내보내는 웹 앱입니다.
바탕화면과 휴대전화에 설치해서 씁니다.

> 저장소 루트의 `index.html` 은 별개의 학생용 식단 앱입니다. 그대로 두었습니다.
> 이 앱은 `app/` 폴더에 있습니다.

## 할 수 있는 것

- **일일 / 주간 / 월간** 화면 — 날짜별, 주별, 달력으로 보기
- **입력 → 확인 대기 → 승인** 흐름. 관리자는 승인 전후 모두 **오기재 수정** 가능, 이력 자동 기록
- **반복일정 탭** — 아침독서·다모임처럼 되풀이되는 활동을 한 번만 등록. 매일 자동으로 붙음
- **방과후 탭** — 강좌를 표로 깔끔하게. 표 그대로 한글·엑셀로 내보내기
- **담당자 자동 매칭** — 업무분장표와 과거 계획을 근거로 담당자·부서를 자동으로 채웁니다 (외부 AI 없이)
- **기간 일정 띠** — 여러 날 이어지는 활동을 일일 화면 맨 위와 주간·월간 달력에 가로 띠로
- **끌어서 날짜 옮기기** — 주간·월간에서 일정을 끌어다 놓으면 이동. **휴대전화는 꾹 눌러서** 끌면 됩니다. 승인된 일정은 관리자 재확인을 거칩니다
- **개인 확인 체크** — 일일교육활동 항목을 각자 체크. 체크하면 취소선이 그어지되 **일정은 사라지지 않고**, 내 체크는 **나에게만** 보입니다
- **바로가기 링크** — 학교 노션 자료실·업무포털 주소를 머리말에 버튼으로
- **나이스 결재용 문구 / 메신저 안내문** 생성 (반복일정·방과후 포함)
- **한글 파일 내보내기** — `.hwpx` 직접 생성, 또는 한글이 바로 여는 HTML
- **업로드** — `.hwpx` · `.xlsx` · `.csv` 파일, 또는 **아무 형식으로나 쓴 글을 붙여넣기**
  → 날짜·시간·대상·장소·담당을 알아서 뽑아내고, 표로 확인한 뒤 제출
- **월중 교육활동계획 표**를 그대로 올리면 한 칸에 쉼표로 나열된 일정을 **각각 따로** 뽑아냅니다
- **구글시트 연동** — 각 계 담당자가 시트에 자유롭게 적으면 정리해서 받아오기
- **실시간 동기화** — 누가 어디서 고쳐도 모든 기기에 즉시 반영 (Firebase)
- **설치(PWA)** — 바탕화면 아이콘, 주소창 없는 창, 오프라인에서도 열람
- **위젯 창** — 430×760 픽셀 작은 창으로 오늘 일정만 띄워두기

## 바로 써 보기

맨 위 폴더의 **`start-windows.bat`** (맥·리눅스는 **`start-mac-linux.command`**) 을 더블클릭하세요.
브라우저가 `http://localhost:8000` 으로 자동으로 열립니다. 설정도 가입도 키도 필요 없습니다.

직접 실행하려면:

```bash
cd app && python3 -m http.server 8000
```

> `index.html` 을 더블클릭하면 동작하지 않습니다(브라우저 보안 규칙). 위 방법으로 여세요.

처음 켜면 [설정] 탭의 **[예시 자료 넣기]** 로 화면이 어떻게 보이는지 바로 확인할 수 있고,
**[예시 자료만 지우기]** 로 예시만 골라 지울 수 있습니다.

자세한 안내 → **[docs/START-LOCAL.md](docs/START-LOCAL.md)**
학교 전체가 같이 쓰려면 → **[docs/SETUP-firebase.md](docs/SETUP-firebase.md)**

## 만들어진 방식

빌드 도구와 외부 라이브러리 없이 순수 ES 모듈로 되어 있습니다.
ZIP · hwpx · xlsx 처리까지 브라우저 기본 기능만 씁니다.
파일을 고쳐서 올리면 그것이 곧 배포입니다.

필요 브라우저: 크롬 · 엣지 103 이상, 사파리 16.4 이상.
