# 로컬로 시작하기

설정도, 가입도, 키도 필요 없습니다. **자료는 그 컴퓨터의 브라우저에만 저장됩니다.**

## 켜는 법

저장소 맨 위 폴더에서 **`start-windows.bat`** 을 더블클릭하세요.
(맥·리눅스는 **`start-mac-linux.command`**)

검은 창이 하나 뜨고 브라우저가 자동으로 `http://localhost:8000` 을 엽니다.
**그 검은 창은 끄지 마세요.** 앱이 켜져 있는 동안 계속 떠 있어야 합니다. 끄려면 `Ctrl + C` 또는 창 닫기.

직접 입력하셔도 됩니다:

```bash
cd app
python3 -m http.server 8000     # 윈도우는 py -3 -m http.server 8000
```

> **⚠️ `index.html` 을 더블클릭하면 빈 화면이 나옵니다.**
> 브라우저 보안 규칙 때문에 `file://` 주소로는 동작하지 않습니다. 반드시 위 방법으로 여세요.
> (혹시 더블클릭하셨다면 화면에 안내가 뜹니다)

## 처음 할 일

1. 이름 · 부서 · 역할을 묻습니다. 혼자 시험해 보실 때는 **역할을 '관리자'** 로 고르세요.
   승인함과 수정 기능이 열립니다.
2. **[설정] 탭 → [예시 자료 넣기]** 를 누르세요.
   이번 주 일정, 반복일정, 방과후 강좌가 한꺼번에 들어가 화면이 어떻게 보이는지 바로 확인됩니다.
3. 둘러본 뒤 **[예시 자료만 지우기]** 를 누르면 예시만 쏙 빠지고
   직접 입력하신 자료는 그대로 남습니다.
4. **[설정] 탭**에서 학교명과 문의처를 실제 값으로 바꾸세요. 결재 문구에 그대로 들어갑니다.

## 이렇게 시험해 보세요

| 해볼 것 | 어디서 |
|---|---|
| 자유 형식 글 붙여넣기 → 자동 표 변환 | [불러오기] 탭 오른쪽 칸 |
| 한글(.hwpx)·엑셀 파일 올리기 | [불러오기] 탭 왼쪽 칸 |
| 나이스 결재 문구 뽑기 | [일일] 탭 → [결재문구·한글파일] |
| 반복일정 한 번 등록하고 매일 붙는지 보기 | [반복일정] 탭 |
| 방과후 표 → 한글로 내보내기 | [방과후] 탭 → [표 내보내기] |
| 작은 창으로 띄워두기 | 오른쪽 위 [위젯 창] |

승인 흐름을 확인하시려면 [설정]에서 역할을 잠깐 **교사**로 바꿔 일정을 하나 올린 뒤,
다시 **관리자**로 바꿔 [승인함]에서 승인해 보세요.

## 로컬 모드에서 알아두실 것

| | |
|---|---|
| 동기화 | **없습니다.** 그 컴퓨터, 그 브라우저에서만 보입니다 |
| 다른 선생님 | 각자 자기 자료만 보게 됩니다. 함께 쓰려면 Firebase가 필요합니다 |
| 휴대전화 | 컴퓨터에 넣은 자료가 휴대전화에는 안 보입니다 |
| 자료 보관 | 브라우저 방문 기록을 **'쿠키 및 기타 사이트 데이터'까지 지우면 함께 지워집니다** |

그래서 로컬은 **"쓸 만한지 며칠 써보는 용도"** 로만 쓰시고,
실제 운영은 Firebase로 넘어가시는 걸 권합니다.

## 백업은 꼭 해두세요

로컬 모드에서 자료를 잃는 가장 흔한 경우가 브라우저 정리입니다.
**[설정] 탭 → [전체 내려받기(JSON)]** 로 파일을 받아 두세요.
나중에 같은 화면의 **[파일에서 복원]** 으로 되돌릴 수 있고,
**Firebase로 옮길 때도 이 파일 하나면 그대로 넘어갑니다.**

## 다음 단계로 넘어갈 때

며칠 써보시고 괜찮다 싶으면:

1. 백업 파일을 받아 둡니다.
2. `docs/SETUP-firebase.md` 를 따라 Firebase를 붙입니다. (30분)
3. 앱에서 **[파일에서 복원]** 으로 백업을 올리면 그동안 넣은 자료가 그대로 올라갑니다.

그전에라도, 앱을 **인터넷 주소(https://)** 로 올려두면 로컬 저장을 그대로 쓰면서도
`start-windows.bat` 없이 주소만으로 열 수 있고 **바탕화면 설치와 휴대전화 사용도 됩니다.**
GitHub Pages가 가장 간단합니다 — 저장소 **Settings → Pages → Branch `main`, 폴더 `/ (root)`**
로 설정하면 `https://<계정>.github.io/class/app/` 주소가 생깁니다.
