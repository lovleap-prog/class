# 한글 파일 · 결재 문구 내보내기

## 어디서 하나

- **일일**: [결재문구·한글파일] 버튼
- **주간 / 월간**: [주간(월간) 계획 내보내기] 버튼
- **방과후**: [표 내보내기] 버튼

## 두 가지 문구

| | 쓰임 |
|---|---|
| **나이스 결재용** | 나이스 일일교육활동 기안 본문에 그대로 붙여넣는 형식 (`1. 교육활동 / 가. …`) |
| **메신저 안내용** | 교직원 메신저·밴드에 올리는 안내문. 결재 문구 대신 써도 됩니다. |

두 문구 모두 **반복(상시) 일정과 방과후학교가 포함**됩니다.
체크박스로 뺄 수도 있고, 창 안에서 문구를 직접 고친 뒤 복사·내려받기 하면 고친 그대로 나갑니다.

예시:

```
2026. 9. 22.(화) 일일교육활동 계획

1. 교육활동
  가. 1~2교시 3학년 안전교육(시청각실, 김민수)
  나. 4교시 5학년 공개수업

2. 상시·반복 운영 활동
  가. 08:40~09:00 전교생 아침독서(각 교실)

3. 방과후학교 (1강좌)
  가. 15:00~16:40 창의로봇과학(과학실, 이수진) / 3~4학년

위와 같이 2026. 9. 22.(화) 일일교육활동을 실시하고자 합니다.
```

## 내려받기 형식 세 가지

### 1. 한글(.hwpx) — 권장, 베타

한글 2010 이상이 쓰는 표준 형식(OWPML)으로 직접 만듭니다. 변환기나 서버가 필요 없습니다.
**한컴오피스 한글 2014 이상**에서 바로 열립니다.

> **베타인 이유**: 한글 버전과 설치 환경에 따라 드물게 "문서 형식이 올바르지 않습니다"가 뜰 수 있습니다.
> 그럴 때는 아래 2번을 쓰세요. 내용은 완전히 같습니다.

문단(줄글)으로만 만듭니다. 나이스 일일교육활동 결재 본문이 원래 줄글이고,
hwpx의 표 구조는 한글 버전을 많이 타서 일부러 넣지 않았습니다.

### 2. 한글용 HTML(.html) — 가장 확실함

한글에서 **[불러오기] → 파일 형식 "HTML 문서"** 로 열면 A4 세로 서식과 **표까지 그대로** 들어옵니다.
방과후 시간표처럼 표가 있는 문서는 이쪽이 더 깔끔합니다.
연 뒤 [다른 이름으로 저장 → 한글 문서(.hwp)] 하면 결재 첨부로 쓸 수 있습니다.

### 3. 복사

클립보드로 복사합니다. 나이스 기안 화면이나 메신저에 그대로 붙여넣으면 됩니다.
**가장 빠른 길이고, 대부분은 이것으로 충분합니다.**

## 올릴 때 (업로드)

[불러오기] 탭에서 받는 형식:

| 형식 | 처리 |
|---|---|
| `.hwpx` | 표가 있으면 표를, 없으면 문단 글을 해석 |
| `.xlsx` | 첫 시트를 표로 읽음 |
| `.csv` / `.tsv` | 표로 읽음 |
| `.txt` | 자유 형식 글로 해석 |
| `.hwp` (구버전) | **바로 못 읽습니다.** 한글에서 [다른 이름으로 저장 → HWPX 문서] 로 저장해 올려주세요 |

구버전 `.hwp` 는 압축된 이진 형식이라 브라우저에서 바로 풀 수 없습니다.
hwpx로 한 번 저장하는 것이 가장 간단하고, 한글 2010 이상이면 모두 지원합니다.

### 월중 교육활동계획 표

학교에서 쓰는 **월중계획 한 장짜리 표**를 그대로 올리면 됩니다.

| 일 | 요일 | 주요 업무 내용 | 비고 |
|---|---|---|---|
| 1 | 화 | 양성평등교육주간(~4), 학교스포츠클럽(10:30, 부서별 장소), 영어원어민 순회 | |

이렇게 읽습니다.

- **한 칸에 쉼표로 나열된 일정을 각각 따로** 뽑습니다. 위 한 줄은 3건이 됩니다.
  괄호 안의 쉼표(`10:30, 부서별 장소`)는 구분자로 보지 않습니다.
- 날짜 칸에 `1` 만 있어도, 문서 제목의 **`2026년 9월`** 을 찾아 `2026-09-01` 로 만듭니다.
- `활동명(시간, 대상, 장소)` 형식에서 시간·대상을 먼저 걷어내고 **남은 것을 장소로** 봅니다.
  그래서 `AI교실`, `별초병설유`, `부서별 장소` 처럼 목록에 없는 장소도 잡힙니다.
- `(~4)` 는 **4일까지 이어지는 기간**으로 읽어 종료일을 채웁니다.
- 내용이 빈 날(주말 등)은 건너뜁니다.
- 쉼표를 빠뜨린 `…(…) 다음활동(…)` 도 두 건으로 나눕니다.

잘못 읽힌 칸은 미리보기 표에서 고친 뒤 등록하면 됩니다.

## 글꼴·크기 바꾸기
