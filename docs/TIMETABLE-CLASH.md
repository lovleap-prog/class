# 주간 시간표와 중복 점검

## 왜 시간표를 따로 뒀나

교과교담(과학·도덕·체육)과 특별실 순회(꿈자람반·보건·영양·국악·원어민)는
**주마다 조금씩 달라집니다.** 교육활동이 주마다 다르니 그에 맞춰 옮기기 때문입니다.

이건 교육활동 목록과 **모양이 다른 자료**입니다.
목록이 아니라 `요일 × 교시` 격자이고, 한 칸에 여러 개가 들어갑니다.
그래서 [시간표] 탭을 따로 두고 **주 단위로** 저장합니다.

**관리자만 고칠 수 있습니다.** 교사는 보기만 합니다.

## 쓰는 법 — 하나씩 치지 마세요

칸을 하나하나 입력하는 건 너무 오래 걸립니다. **복사해서 고치는 것**이 정상 흐름입니다.

### 처음 한 번: 파일에서 통째로

**[파일에서 가져오기]** → 이미 쓰고 계신 **교담 시간표 한글(.hwpx) 파일을 끌어다 놓으면**
요일·교시 격자를 그대로 읽어 한 번에 넣습니다. 엑셀(.xlsx)·CSV도 됩니다.

- 한 칸에 여러 줄이 있으면 **줄마다 항목 하나**로 읽습니다
- `공자람반1,2` 의 쉼표는 이름의 일부이므로 나누지 않습니다
- `꿈자람·보건·영양·국악·원어민·사서·순회·돌봄` 등이 들어간 항목은 **특별실**로 자동 분류합니다
- 넣기 전에 몇 칸이 읽혔는지 요일별로 보여줍니다

한글·엑셀에서 표를 **복사해 붙여넣어도** 됩니다.
표를 옮기기 어려우면 줄 형식도 받습니다.

```
월 1교시 공자람반1,2 / 과학5
화 1교시 공자람반1,2 / 영어(원어민) / 국악5
```

### 그다음 주부터

| 하고 싶은 것 | 방법 |
|---|---|
| 지난 주와 거의 같다 | **[지난 주 복사]** 후 달라진 칸만 수정 |
| 한 칸을 다른 칸에도 | 칸 오른쪽 위 **복사 단추(⧉)** → 붙여넣을 칸 클릭 |
| 요일 하나를 통째로 | **요일 이름 클릭**(복사) → 붙여넣을 요일 이름 클릭 |
| 끌면서 복사 | **Ctrl**(맥은 ⌘ 또는 Alt)을 누른 채 끌어 놓기 |
| 그냥 옮기기 | 끌어서 다른 요일·교시로 (휴대전화는 꾹 눌러서) |

복사한 상태에서는 위쪽에 `📋 복사함: 월 1교시 2개` 안내줄이 뜹니다.
같은 내용을 여러 칸에 **연달아 붙여넣을 수 있고**, 끝나면 [복사 끝내기] 를 누르세요.

## 중복(충돌) 점검

### 무엇을 중복으로 보나

**같은 시간**인 것만으로는 중복이 아닙니다. 3학년 수업과 5학년 수업은 같은 교시라도 괜찮습니다.
셋 중 하나라도 겹쳐야 중복입니다.

| 겹치는 것 | 왜 |
|---|---|
| **담당자** | 한 사람이 동시에 두 곳에 있을 수 없습니다 |
| **장소** | 한 교실을 동시에 둘이 쓸 수 없습니다 |
| **학년** | 같은 학년이 동시에 두 활동을 할 수 없습니다 |

`전교생`은 1~6학년 전부로 봅니다. 그래서 **전교생 행사는 모든 학년 수업과 겹칩니다.**

### 어디까지 같이 보나

교육활동 · 반복일정 · 시간표를 **한꺼번에** 봅니다.
시간표만 따로 보면 "화요일 3교시 과학5" 와 "그날 3교시 소방훈련" 이 겹치는 걸 놓칩니다.

### 어떻게 보이나

| 화면 | 표시 |
|---|---|
| **일일** | 맨 위 「중복 N건」 목록 + 겹치는 카드에 빨간 테두리와 사유 |
| **시간표** | 겹치는 칸이 빨간 점선 + 아래 「중복 N건」 목록 |

`'소방대피 훈련' 과(와) 겹침 (장소 운동장, 1·2·3·4·5·6학년)` 처럼 **왜 겹치는지** 함께 나옵니다.

> **중복이라고 해서 자동으로 고치지 않습니다.** 겹쳐도 되는 경우가 많기 때문입니다.
> 알려만 드리니 보시고 판단하세요.

### 시간을 알 수 없으면 판정하지 않습니다

`방과후`, 빈 시간처럼 몇 시인지 알 수 없는 것은 중복 검사에서 빠집니다.
**모르는 것을 중복이라고 우기지 않습니다.**

교시와 시각의 대응은 [설정] → **교시 시각** 에서 학교 일과표에 맞춰 고쳐두세요.
이 표로 `3교시` 와 `10:30` 이 겹치는지를 계산합니다.

## 반복일정이 행사와 겹칠 때

> 매주 화요일 10:30 스포츠클럽인데, 어떤 화요일엔 그 시간에 소방훈련이 있다

이럴 때 [일일] 화면 「상시·반복 운영」의 **[이 날만 빼기]** 를 누르세요.

- **그 날짜에만** 반복일정이 빠집니다
- **다음 주 화요일부터는 그대로 운영**됩니다
- 결재 문구와 안내문에서도 그 날만 빠집니다

규칙 자체를 끄면(운영 → 중지) **다른 주까지 전부 사라집니다.** 그럴 때 쓰는 것이 아닙니다.

빼둔 날짜는 [반복일정] 탭에 `2일 제외` 처럼 표시되고, 눌러서 한 번에 되돌릴 수 있습니다.

겹쳐도 괜찮은 경우(예: 아침독서와 아침 방송)는 **그냥 두시면 됩니다.**
중복 표시는 알림일 뿐 강제하지 않습니다.
