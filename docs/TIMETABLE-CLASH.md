# 주간 시간표와 중복 점검

## 왜 시간표를 따로 뒀나

교과교담(과학·도덕·체육)과 특별실 순회(꿈자람반·보건·영양·국악·원어민)는
**주마다 조금씩 달라집니다.** 교육활동이 주마다 다르니 그에 맞춰 옮기기 때문입니다.

이건 교육활동 목록과 **모양이 다른 자료**입니다.
목록이 아니라 `요일 × 교시` 격자이고, 한 칸에 여러 개가 들어갑니다.
그래서 [시간표] 탭을 따로 두고 **주 단위로** 저장합니다.

**관리자만 고칠 수 있습니다.** 교사는 보기만 합니다.

## 쓰는 법 — 하나씩 치지 마세요

칸을 하나하나 입력하는 건 너무 오래 걸립니다. **복사해서 고치는 것**이 정상 흐름입니다.

### 처음 한 번: 파일에서 통째로

**[파일에서 가져오기]** → 이미 쓰고 계신 **교담 시간표 한글(.hwpx) 파일을 끌어다 놓으면**
요일·교시 격자를 그대로 읽어 한 번에 넣습니다. 엑셀(.xlsx)·CSV도 됩니다.

- 한 칸에 여러 줄이 있으면 **줄마다 항목 하나**로 읽습니다
- `공자람반1,2` 의 쉼표는 이름의 일부이므로 나누지 않습니다
- `꿈자람·보건·영양·국악·원어민·사서·순회·돌봄` 등이 들어간 항목은 **특별실**로 자동 분류합니다
- 넣기 전에 몇 칸이 읽혔는지 요일별로 보여줍니다

한글·엑셀에서 표를 **복사해 붙여넣어도** 됩니다.
표를 옮기기 어려우면 줄 형식도 받습니다.

```
월 1교시 공자람반1,2 / 과학5
화 1교시 공자람반1,2 / 영어(원어민) / 국악5
```

### 칸에 보이는 것

```
┌──────────────────────────┐
│ 과학5           실험 준비 │  ← 비고는 오른쪽에
│ 과학실                    │  ← 장소는 제목 아래
└──────────────────────────┘
```

**비고**에 적은 내용이 칸 오른쪽 여백에 함께 나옵니다.
칸이 좁으면 `원어민 교사 출…` 처럼 줄여 보여주고, 마우스를 올리면 전체가 뜹니다.
일일 화면의 「교과교담·특별실」 줄에도 같이 나옵니다.

### 그다음 주부터

| 하고 싶은 것 | 방법 |
|---|---|
| 지난 주와 거의 같다 | **[지난 주 복사]** 후 달라진 칸만 수정 |
| 한 칸을 다른 칸에도 | 칸 오른쪽 위 **복사 단추(⧉)** → 붙여넣을 칸 클릭 |
| 요일 하나를 통째로 | **요일 이름 클릭**(복사) → 붙여넣을 요일 이름 클릭 |
| 끌면서 복사 | **Ctrl**(맥은 ⌘ 또는 Alt)을 누른 채 끌어 놓기 |
| 그냥 옮기기 | 끌어서 다른 요일·교시로 (휴대전화는 꾹 눌러서) |

복사한 상태에서는 위쪽에 `📋 복사함: 월 1교시 2개` 안내줄이 뜹니다.
같은 내용을 여러 칸에 **연달아 붙여넣을 수 있고**, 끝나면 [복사 끝내기] 를 누르세요.

## 중복(충돌) 점검

### 무엇을 중복으로 보나

**같은 시간**인 것만으로는 중복이 아닙니다. 3학년 수업과 5학년 수업은 같은 교시라도 괜찮습니다.
셋 중 하나라도 겹쳐야 중복입니다.

| 겹치는 것 | 왜 |
|---|---|
| **담당자** | 한 사람이 동시에 두 곳에 있을 수 없습니다 |
| **장소** | 한 교실을 동시에 둘이 쓸 수 없습니다 |
| **학년** | 같은 학년이 동시에 두 활동을 할 수 없습니다 |

`전교생`은 1~6학년 전부로 봅니다. 그래서 **전교생 행사는 모든 학년 수업과 겹칩니다.**

### 어디까지 같이 보나

교육활동 · 반복일정 · 시간표를 **한꺼번에** 봅니다.
시간표만 따로 보면 "화요일 3교시 과학5" 와 "그날 3교시 소방훈련" 이 겹치는 걸 놓칩니다.

### 어떻게 보이나

| 화면 | 표시 |
|---|---|
| **일일** | 맨 위 「중복 N건」 목록 + 겹치는 카드에 빨간 테두리와 사유 |
| **시간표** | 겹치는 칸이 빨간 점선 + 아래 「중복 N건」 목록 |

`'소방대피 훈련' 과(와) 겹침 (장소 운동장, 1·2·3·4·5·6학년)` 처럼 **왜 겹치는지** 함께 나옵니다.

> **중복이라고 해서 자동으로 고치지 않습니다.** 겹쳐도 되는 경우가 많기 때문입니다.
> 알려만 드리니 보시고 판단하세요.

### 시간을 알 수 없으면 판정하지 않습니다

`방과후`, 빈 시간처럼 몇 시인지 알 수 없는 것은 중복 검사에서 빠집니다.
**모르는 것을 중복이라고 우기지 않습니다.**

교시와 시각의 대응은 [설정] → **시정표** 에서 학교 일과표에 맞춰 고쳐두세요.
이 표로 `3교시` 와 `10:30` 이 겹치는지를 계산합니다.

## 시정이 하나가 아닐 때 (단축 · 수업공개)

학교는 시정을 한 벌만 쓰지 않습니다. 시정이 틀리면 **중복 판정과 결재 문구의 시각이 함께 틀어지므로**
여러 벌을 둘 수 있게 했습니다. 1년에 몇 번 있는 일이니 **기본은 건드리지 않고 그때만 바꾸는** 방식입니다.

### 1. 시정표 만들기

[설정] → **시정표** 에서 [+ 단축 시정] · [+ 수업공개 시정] 을 누르면 기본 시정을 본떠 한 벌 더 생깁니다.
이름과 시각을 학교에 맞게 고치세요. **기본 시정은 반드시 하나** 있어야 합니다.

### 2. 단축수업 하는 날

[일일] 화면 날짜 옆의 **시정 고르기**에서 `단축 시정` 을 고릅니다. 관리자만 보입니다.

- 그 날짜의 모든 활동이 단축 시정으로 계산됩니다
- 카드에 `2교시 (09:35~10:05)` 처럼 **실제 시각**이 함께 나옵니다
- 결재 문구 맨 위에 `※ 단축 시정 운영`, 메신저 안내문에 `※ 오늘은 단축 시정입니다.` 가 붙습니다
- 교사에게는 고르기 대신 `단축 시정` 표시만 보입니다

### 3. 수업공개 — 시정이 이원화되는 날

수업공개를 하면 **공개 학년만** 다른 시정으로 움직입니다.
(3교시를 10:30~11:10로 당기고 중간 쉬는 시간을 따로 두는 식. 다른 선생님들이 참관하러 가야 하니까요)

이럴 때는 **날짜가 아니라 그 활동에** 시정을 지정합니다.
활동 추가·수정 창의 **시정** 칸에서 `수업공개 시정` 을 고르세요.

```
3교시 (10:30~11:10) 3학년 수업공개   [수업공개 시정]   ← 공개 학년
3교시               5학년 과학                          ← 나머지 학년(기본 시정)
```

같은 '3교시' 라도 **서로 다른 시각으로 계산**되므로,
겹치는지 아닌지를 제대로 가려냅니다. 예를 들어 이수진 선생님이 공개수업 참관을 가면서
같은 시간에 5학년 과학이 잡혀 있으면 **담당자 겹침으로 잡힙니다.**

### 어느 시정이 적용되나

좁은 쪽이 이깁니다.

```
활동에 지정한 시정  →  그 날짜에 지정한 시정  →  기본 시정
```

그래서 단축수업 날이어도 특정 활동만 기본 시정으로 못박을 수 있습니다.

## 반복일정이 행사와 겹칠 때

> 매주 화요일 10:30 스포츠클럽인데, 어떤 화요일엔 그 시간에 소방훈련이 있다

이럴 때 [일일] 화면 「상시·반복 운영」의 **[이 날만 빼기]** 를 누르세요.

- **그 날짜에만** 반복일정이 빠집니다
- **다음 주 화요일부터는 그대로 운영**됩니다
- 결재 문구와 안내문에서도 그 날만 빠집니다

규칙 자체를 끄면(운영 → 중지) **다른 주까지 전부 사라집니다.** 그럴 때 쓰는 것이 아닙니다.

빼둔 날짜는 [반복일정] 탭에 `2일 제외` 처럼 표시되고, 눌러서 한 번에 되돌릴 수 있습니다.

겹쳐도 괜찮은 경우(예: 아침독서와 아침 방송)는 **그냥 두시면 됩니다.**
중복 표시는 알림일 뿐 강제하지 않습니다.

## 여러 칸을 한 번에 — 고르기

칸을 하나씩 지우기가 번거로울 때 씁니다. 위쪽 **[☑ 고르기]** 를 누르면 시작합니다.

```
☑ 3칸 골랐습니다    [이 주 전체 (10)] [고른 것 해제] [⧉ 복사] [🗑 3칸 지우기]
```

- 고르는 중에는 칸을 눌러도 **수정 창이 열리지 않고 골라집니다.** 다시 누르면 해제
- 고른 칸은 파란 테두리로 표시됩니다
- **[이 주 전체]** 로 그 주 전부를 한 번에 고릅니다

### 지우기 — 단추로도, 끌어서도

화면 아래에 **휴지통**이 있습니다.

- 골라 둔 것이 있으면 휴지통을 **누르기만** 해도 지워집니다
- 칸을 **끌어다 휴지통에 놓아도** 지워집니다. 골라 둔 것이 있으면 그것들까지 한꺼번에
- 아무것도 안 골랐으면 끌어다 놓은 그 칸 하나만

지우기 전에 한 번 되묻습니다. 지운 뒤에도 고르기는 켜져 있어 이어서 정리할 수 있습니다.

### 복사 — 골라서 붙여넣기

고른 뒤 **[⧉ 복사]** 를 누르면 복사함에 담기고 고르기가 끝납니다.
그 다음 **붙여넣을 칸을 누르면** 한꺼번에 들어갑니다.

원래 있던 복사 기능도 그대로입니다.

| | |
|---|---|
| 칸 하나 복사 | 칸 오른쪽 위 ⧉ |
| 요일 통째로 | 요일 이름을 누르면 복사, 다른 요일 이름을 누르면 붙여넣기 |
| **고른 것만** | [☑ 고르기] → 골라서 → [⧉ 복사] |
| 지난 주 통째로 | [지난 주 복사] |
| 한 칸씩 옮기기 | 칸을 끌어서. Ctrl(또는 Alt)을 누른 채 놓으면 복사 |
