# 선생님용 설치 안내 (그대로 인쇄해서 나눠주셔도 됩니다)

## 설치가 필요한가요?

아닙니다. **주소만 열면 바로 씁니다.** 다만 설치해 두면 바탕화면 아이콘으로 한 번에 열리고,
주소창 없는 깔끔한 창으로 뜨며, 인터넷이 잠깐 끊겨도 열립니다.

설치 파일(exe)을 돌리는 게 아니라, 크롬/엣지가 **바로가기 앱**을 만들어 주는 방식입니다.
그래서 **관리자 권한이 필요 없고**, 학교 PC 보안 정책에 걸리지 않습니다.

## 윈도우 컴퓨터 (크롬 / 엣지)

1. 크롬 또는 엣지로 아래 주소를 엽니다.
   ```
   (학교에서 안내한 주소)
   ```
2. 주소창 오른쪽 끝의 **설치 아이콘(⊕ 또는 모니터 모양)** 을 누릅니다.
   - 엣지: `···` → **앱** → **이 사이트를 앱으로 설치**
   - 크롬: `⋮` → **캐스트, 저장 및 공유** → **페이지를 앱으로 설치**
3. [설치] → 바탕화면에 **교육활동** 아이콘이 생깁니다.
4. 처음 한 번만 **이름 / 부서 / 역할**을 입력합니다.

## 휴대전화

- **안드로이드(크롬)**: 주소 열기 → `⋮` → **홈 화면에 추가**
- **아이폰(사파리)**: 주소 열기 → 공유 버튼 → **홈 화면에 추가**

## 바탕화면을 얼마나 차지하나요?

| | 크기 |
|---|---|
| 바탕화면 아이콘 | 보통 아이콘 **1칸** (48~64px). 다른 프로그램 바로가기와 같습니다. |
| 앱 창(기본) | 창 크기는 자유롭게 조절. 전체화면으로 써도 됩니다. |
| **위젯 창** | **가로 430 × 세로 760 픽셀** |

위젯 창은 앱 오른쪽 위 **[위젯 창]** 버튼을 누르면 뜹니다.
1920×1080 화면 기준으로 **가로의 약 1/4, 화면 면적의 약 15%** 입니다.
한글이나 나이스를 열어둔 옆에 세워두고 오늘 일정을 계속 보기 좋은 크기입니다.

위젯 창에는 **오늘의 교육활동 + 상시 운영 활동 + 방과후 강좌**가 한눈에 보이고,
아래 [결재문구] 버튼으로 나이스에 붙여넣을 문구를 바로 복사할 수 있습니다.

## 자료는 언제 맞춰지나요?

학교가 Firebase 공유로 설정해 두었다면 **저장하는 즉시** 모든 선생님 화면에 반영됩니다.
새로 고침할 필요가 없습니다. 휴대전화에서 고쳐도 마찬가지입니다.

인터넷이 끊긴 동안에는 화면이 그대로 열리고,
연결되면 그 사이의 변경이 자동으로 합쳐집니다.

## 자주 묻는 것

**Q. 제가 입력한 게 바로 반영되나요?**
아니요. 선생님이 올리면 **확인 대기** 상태가 되고, 담당 선생님이 **승인**해야 확정됩니다.
잘못 적은 부분은 담당 선생님이 승인 전에 고칠 수 있습니다.

**Q. 반려됐다고 뜹니다.**
[승인함] 탭에서 반려 사유를 볼 수 있습니다. 고쳐서 다시 제출하세요.

**Q. 매번 똑같은 일정(아침독서 등)도 매일 적어야 하나요?**
아니요. [반복일정] 탭에 한 번만 등록하면 매일 자동으로 붙고, 결재 문구에도 들어갑니다.

**Q. 일정을 다른 날로 옮기고 싶어요.**
[주간]이나 [월간] 화면에서 **일정을 끌어다 다른 날짜 칸에 놓으면** 됩니다.
여러 날 이어지는 일정(띠)도 통째로 옮겨지고, 기간 길이는 그대로 유지됩니다.

- 옮길 수 있는 것은 **내가 올린 일정**뿐입니다. 남이 올린 것은 끌리지 않습니다.
- 이미 승인된 일정을 옮기면 **관리자 확인을 다시 받습니다.** 반려되면 원래 날짜로 돌아갑니다.
- 관리자는 바로 옮겨지고, 누가 언제 옮겼는지 이력이 남습니다.
- **휴대전화에서는 끌기가 안 됩니다.** 일정을 눌러 [수정]에서 날짜를 바꾸세요.

**Q. 일정 옆 체크박스는 뭔가요?**
각자 "나는 이거 확인했다"를 표시하는 칸입니다. 체크하면 취소선이 그어집니다.
**일정이 지워지는 것이 아니고**, 내 체크는 **나에게만 보입니다.**
다른 선생님 화면은 그대로이니 마음껏 쓰셔도 됩니다. [내 체크 지우기]로 한 번에 되돌립니다.

**Q. 설치한 앱을 지우려면?**
앱 창의 `⋮` → **제거**. 또는 윈도우 [설정 → 앱]에서 지웁니다. 자료는 서버에 남습니다.
