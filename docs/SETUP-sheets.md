# 구글시트 연동 (담당자 자유 입력 → 자동 정리)

"각 계 담당자가 일정한 형식으로 자유롭게 입력하면 자동으로 들어오게" 하는 방법입니다.

## 왜 시트를 같이 쓰나

- 담당자들이 이미 익숙합니다. 새 계정을 만들 필요가 없습니다.
- 여러 명이 각자 줄에 적어두면 한꺼번에 받아올 수 있습니다.
- 앱에 못 들어오는 분(기간제·외부 강사)도 시트 링크만 있으면 됩니다.

원본 자료는 앱(Firestore)에 있고, 시트는 **입력 창구**입니다.

## 1. 시트 만들기

1. 새 구글 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script**
3. 이 저장소의 `sheets/Code.gs` 내용을 통째로 붙여넣고 저장합니다.
4. 시트로 돌아와 새로 고치면 상단에 **[교육활동]** 메뉴가 생깁니다.
5. **[교육활동 → 시트 처음 만들기]** 를 누르면 `자유입력` / `정리됨` 두 시트가 생깁니다.

## 2. 담당자에게 안내하기

`자유입력` 시트에 한 줄씩 이렇게 적으면 됩니다. **형식은 자유입니다.**

| 작성자 | 부서/계 | 내용(형식 자유) |
|---|---|---|
| 김민수 | 교무기획부 | 9월 22일(월)<br> - 1~2교시 3학년 안전교육 (시청각실)<br> - 전교생 아침독서 08:40 |
| 이수진 | 생활인성부 | 9/24~9/26 5학년 현장체험학습 경주 |

알아서 뽑아내는 것들:

| 적는 예 | 뽑아내는 값 |
|---|---|
| `9월 22일`, `9/22`, `2026-09-22`, `22일`, `22(월)` | 날짜 |
| `9/24~9/26` | 시작일 + 종료일 |
| `3교시`, `1~2교시`, `10:00~11:40`, `아침활동`, `방과후` | 시간 |
| `3학년`, `5학년 2반`, `1~2학년`, `전교생` | 대상 |
| `시청각실`, `체육관`, `도서관` 등 | 장소 |
| `김민수 선생님`, `담당: 김민수` | 담당 |
| `안전`·`대피`·`보건` / `회의`·`연수` / `체험`·`대회` | 분류 자동 지정 |

날짜만 적힌 줄은 **그 아래 줄들의 날짜 머리글**로 취급합니다.

## 3. 정리하고 앱으로 보내기

1. 시트에서 **[교육활동 → 자유입력 → 정리하기]**
   → `정리됨` 시트에 날짜·시간·활동명·대상·장소·담당·부서로 정돈됩니다.
   여기서 틀린 칸을 직접 고쳐도 됩니다.
2. Apps Script 화면에서 **배포 → 새 배포 → 유형 '웹 앱'**
   - 실행 계정: **나**
   - 액세스 권한: **링크가 있는 모든 사용자** (또는 학교 조직 내)
   - 만들어진 `.../exec` 주소를 복사
3. 앱의 **[불러오기]** 탭 → '구글시트에서 가져오기' 칸에 그 주소를 넣고 **[가져오기]**
4. 미리보기 표에서 확인·수정 → **[등록하기]** → 관리자 승인

> 주소는 한 번만 넣으면 브라우저에 기억됩니다.
> 조직 정책 때문에 웹앱 배포가 막혀 있으면, 시트를 **CSV로 내려받아**
> [불러오기] 탭에 끌어다 놓으면 똑같이 동작합니다.

## 4. 구글 설문지로 받기

담당자가 시트를 직접 건드리는 게 부담스러우면 구글 설문지를 만들고
응답 시트 이름을 `자유입력` 으로 바꾸면 그대로 동작합니다.
(질문: 작성자 / 부서 / 내용 — 순서만 맞추면 됩니다)

## 5. 반대로, 시트에 백업하기

앱 **설정** 탭 → **[전체 내려받기(JSON)]** 로 받은 파일을 보관하세요.
학기 말 보고용 표가 필요하면 [방과후] 탭의 **[표 내보내기 → CSV]** 로 받아 시트에 붙여넣으면 됩니다.
